## Glosario de Términos

| Término | Definición |
|---------|------------|
| **Cero Absoluto** | Temperatura más baja posible: 0 K o -273.15 °C |
| **Energía del Punto Cero** | Energía residual cuántica a 0 K |
| **Entropía** | Medida del desorden de un sistema |
| **Interferencia Coherente** | Superposición de ondas en fase |
| **Esqueleto del Campo** | Regiones de mínima energía en el espacio-tiempo |
| **Rebote Térmico** | Fluctuaciones de temperatura durante el enfriamiento |
